# Ares

App web para el móvil que acompaña el entrenamiento en el gimnasio:

- Muestra el entreno que toca cada día y sus ejercicios.
- Permite apuntar las series (peso y repeticiones).
- Incluye temporizador de descanso y cronómetro.
- Deja cambiar un ejercicio por otro parecido.
- Enseña el historial y la evolución de cada ejercicio.
- Funciona sin conexión y sincroniza al recuperarla.

Uso personal: necesita una configuración privada para funcionar.
